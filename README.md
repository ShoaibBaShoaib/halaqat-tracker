# halaqat-tracker
ننظام مرن وخفيف لإدارة وتوثيق الحضور والغياب في الحلقات التعليمية والقرآنية (مثل حلقات ما بعد الفجر). يعمل النظام بالكامل على متصفح العميل (Client-side) دون الحاجة لقواعد بيانات خارجية، مما يوفر سرعة وخصوصية عالية وحفظاً محلياً آمناً للبيانات. رغم أن المشروع بُرمج في البداية لخدمة "مركز أحمد للطالب الجامعي"، إلا أنه صُمم ليكون مفتوح المصدر وقابلاً للتخصيص المباشر من واجهة الإعدادات ليخدم أي مسجد، مركز تعليمي، أو مؤسسة.
​أبرز المميزات (Features):
​العمل دون اتصال: تطبيق PWA قابل للتثبيت على الهواتف ويعمل بكفاءة بدون إنترنت.
​إدارة الحضور الدقيقة: تحضير يومي بحالات متعددة (حاضر، غائب بعذر، غائب بدون عذر) مع قفل الأيام المستقبلية.
​تتبع الانضباط: تتبع آلي لتجاوزات الحد الأسبوعي للغياب وتنبيه المشرف للأيام السابقة غير المحضرة.
​التقارير الرسمية: توليد تقارير إدارية احترافية للطباعة (PDF) بصفحات طولية للإحصائيات وعرضية لسجل التحضير التفصيلي.
​المشاركة السريعة: تصدير التقرير اليومي بنسق نصي جاهز للإرسال المباشر عبر مجموعات الواتساب.
​أمان البيانات: استخراج واستعادة نسخ احتياطية (JSON) محلياً، وتصدير البيانات إلى Excel.
